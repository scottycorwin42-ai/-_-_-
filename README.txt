AISHA SELLER — ГОТОВЫЙ САЙТ ДЛЯ GITHUB PAGES

Этот архив уже готов к публикации. Ничего собирать и устанавливать не нужно.

1. Распакуйте ZIP-архив.
2. Создайте на GitHub новый публичный репозиторий.
3. Загрузите в него ВСЁ содержимое распакованной папки:
   index.html, script.js, папку assets и остальные файлы.
4. Нажмите Commit changes.
5. Откройте Settings → Pages.
6. В разделе Source выберите Deploy from a branch.
7. Выберите ветку main и папку /(root), затем нажмите Save.
8. Подождите 2–5 минут. GitHub покажет ссылку на опубликованный сайт.

Важно: файл index.html должен лежать в корне репозитория, а не внутри дополнительной папки.
